# 莫弈·Vilhelm

《未定事件簿》角色 **莫弈** 的个人成长时间线记录与展示站（粉丝向非官方作品）。

纯前端静态站点：无后端、无数据库，内容以 JSON 数据文件维护；托管方案待定（Gitee Pages 已下线）。

## 功能

- **多条时间线**：主线剧情线、个人成长线、活动/节日线，可切换浏览
- **左右交替时间轴**：桌面端中线居中、卡片左右交错；移动端退化为单侧；事件按剧情时间**倒序**展示，卡片带 16:9 首图缩略图，点击卡片进入**独立详情页**（event.html）
- **事件详情页**：完整正文、台词引用、插图灯箱、语音播放、标签角色、点赞，及同时间线"上一条/下一条"翻页
- **背景图模式**：全局背景图 + 按图**自动取色**（Canvas 提取主色与亮度 → 生成遮罩与氛围色），换任意背景图无需改代码
- **事件级背景图**：事件可单独配置背景图，进入其详情页时页面背景随之切换
- **类别/标签筛选**：剧情/章节、角色状态/成长阶段、事件类型、地点/时期 四维度组合筛选
- **关键词搜索**：标题、正文、台词引用、标签
- **事件详情**：正文、插图灯箱、语音播放、台词引用、出场角色、重要度标记
- **点赞**：浏览器本地存储（访客各自可见）
- **统计面板**：事件总数、各时间线分布、成长阶段分布、素材量
- **响应式**：桌面与移动端适配

├── event.html         # 事件详情页（?id=事件id）

├── about.html         # 关于 / 版权声明

├── assets/            # 素材（图片 / 语音）
│   ├── images/moyi/
│   └── audio/moyi/
├── data/              # 数据文件（发布物）
│   ├── site.json      # 站点配置 + 角色 + 背景图 + 功能开关
│   ├── timelines.json # 时间线定义
│   ├── tags.json      # 类别与标签

## 本地运行

浏览器直接打开 HTML 会因 `fetch` 跨域限制无法加载数据，请用本地 HTTP 服务器：

```bash
# Python 方式
python -m http.server 8000
# 然后访问 http://localhost:8000/
```

## 数据维护

- 内容数据在 `data/*.json`：`site.json`（站点/角色/背景图/功能开关）、`timelines.json`（时间线）、`tags.json`（类别标签）、`events.json`（事件）。
- 事件按 `order` 字段在时间线内排序（剧情时间，展示倒序）；`stage` 仅作展示。
- 事件可配置 `bgImage`（事件级背景图，展开详情时替换全局背景）。
- 素材文件按时间线分目录存放：`assets/images/moyi/{timelineId}/`（如 `growth/生日-20260927-1.jpg`），文件名规则 `活动名-日期[-序号]`；语音放 `assets/audio/moyi/{timelineId}/`；全局背景图等站点级素材放 `assets/images/moyi/` 根目录。
- 修改数据后推送到仓库，再按所选托管平台的规则更新部署。
