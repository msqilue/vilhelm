# 部署说明 — Nginx 静态托管「莫弈·Vilhelm」

## 方式 A：Windows 本机部署（当前项目目录直接托管）

1. 下载 Windows 版 Nginx：http://nginx.org/en/download.html（Stable 版，如 nginx-1.26.x）
   解压到 `C:\nginx-1.26.x`（路径别带中文/空格）

2. 启用站点配置（二选一）：
   - 把 `nginx-vilhelm.conf` 内容**追加**到 `C:\nginx-1.26.x\conf\nginx.conf` 的 `http {}` 块内；
   - 或复制为 `C:\nginx-1.26.x\conf\vilhelm.conf`，在 `nginx.conf` 的 `http {}` 末尾加一行：
     `include vilhelm.conf;`

3. 启动测试：
   ```bat
   cd C:\nginx-1.26.x
   nginx -t              :: 配置检查，提示 successful 即可
   start nginx           :: 启动
   ```
   浏览器访问 http://localhost 即看到站点（80 端口被占则改 listen 8080 等）

4. （可选）注册 Windows 服务自启动（用 NSSM，你已用过）：
   ```bat
   nssm install nginx C:\nginx-1.26.x\nginx.exe -p C:\nginx-1.26.x\conf
   nssm set nginx AppDirectory C:\nginx-1.26.x
   nssm start nginx
   ```

5. 改代码后无需重启：项目目录即站点目录，刷新即可（带 ?v= 版本参数自动拉新）

## 方式 B：Linux 服务器部署（有公网 IP 时）

1. 安装：`sudo apt install nginx`（Ubuntu）
2. 把站点文件传到服务器：
   `scp -r E:\Project\Vilhelm\* user@server:/var/www/vilhelm/`
3. 建站点配置：
   ```bash
   sudo cp deploy/nginx-vilhelm.conf /etc/nginx/sites-available/vilhelm
   # 编辑：root 改 /var/www/vilhelm，server_name 改你的域名/IP
   sudo ln -s /etc/nginx/sites-available/vilhelm /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   ```
4. 安全组/防火墙放行 80 端口

## 注意
- 外网访问前提：本机需公网 IP 或内网穿透（frp/花生壳等）；否则仅局域网内可访问
- 80 端口冲突：先 `netstat -ano | findstr :80` 查占用，冲突则改 listen
- 后续推送代码后，服务器上 `git pull`（若服务器克隆了仓库）或重新 scp 即可更新
